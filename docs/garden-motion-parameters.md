# 树的动态参数

基准日期：2026-10-19。对应 `/garden/` 与 `/en/garden/` 的当前实现，叶簇摆幅为 **3%**。小树、中树、大树共用这些相对风动参数；文中的 112 根小枝、14 根粗主枝、8794 片叶及屏幕位移统计专指成树。阶段形态与数量见 [成长参数](garden-growth.md)。

## 参数总览

| 运动部分 | 当前基础摆幅 | 周期 | 作用范围 |
| --- | --- | --- | --- |
| 叶簇摆动 | 小枝弧长 × **0.03（3%）** | **8 秒** | 112 根小枝分别带动自己的子枝和叶片，主要决定树冠整体移动感 |
| 末端细枝弯曲 | 末端枝条弧长 × **0.00896（0.896%）** | **8 秒** | 在所属叶簇的运动上增加枝梢局部弯曲 |
| 叶片主体弯曲 | 叶长 × **0.05（5%）** | **8 秒** | 叶片自身向叶尖逐渐弯曲 |
| 叶缘微动 | 叶长 × **0.01（1%）** | **4 秒 + 8/3 秒** | 两侧边缘微动，慢波占 65%，快波占 35% |
| 风力强弱变化 | 上述运动乘以 **0.7–1** | **8 秒** | 强弱峰值在树自身坐标中从左向右经过 |
| 根部、主干、14 根粗主枝 | **0** | — | 保持固定 |
| 手动切换观察方向 | 绕 Y 轴切换至 **0° / 90° / 180°** | **300ms / 次** | 仅点击正面、侧面、背面时发生 |

这里的百分比是相对于各自枝长或叶长的**位移系数**，不是旋转角度、屏幕宽度百分比，也不是最终往返距离。实际位移还受到个体强度、弯曲权重、波形与风力系数影响。

各层依次叠加，方向、参考长度和相位不同，不能将 `3% + 0.896% + 5% + 1%` 当作整树摆幅。表中基础幅度也不意味着每一片叶子都会达到该幅度。

## 叶簇摆动：控制整体移动感

来源：[garden-branch-motion.ts](../src/lib/garden-branch-motion.ts) 的 `createBranchWind`、`branchFlex`，以及 [garden-tree.ts](../src/lib/garden-tree.ts) 的 `grow`。

| 参数 | 当前值 / 规则 | 含义 |
| --- | --- | --- |
| 基础摆幅 | `length * .03` | `length` 是所属小枝曲线的弧长 |
| 单枝强度 | `.85 + .15 * random`，约 0.85–1 | 同样长度的小枝有轻微强弱差异；输入再限制到 0–1 |
| 作用层级 | `depth === 2` 创建，深度 3 / 4 继承 | 每根小枝及其后代共享同一个位移场 |
| 小枝数量 | 14 根粗主枝 × 每根 8 个 = 112 | 粗主枝本身不动 |
| 过渡范围 | 小枝弧长 × **1.3** | 以根部到末端的轴向投影计算位置权重 |
| 权重 | `u = clamp(coordinate, 0, 1)`；`u²(3−2u)` | 根部为零，远端饱和到 1，不无限放大 |
| 权重导数 | `6u(1−u)` | 根部弯曲斜率为零，避免硬折点 |
| 周期 | `time * .125`，即 8 秒 | 使用平滑三角波，输出 −1 至 1 |
| 组内相位 | `groupPhase + index * .5 + jitter` | 按生成顺序相邻的小枝约错开半周期 |
| 相位扰动 | `(random − .5) * .06`，约 ±0.03 周期 | 单枝相对规则位置约 ±0.24 秒；不同组的起始相位独立 |
| 风力相位取样 | 所属小枝曲线参数 `t=.5` 的位置 | 该小枝的后代共享同一强弱变化，保持枝叶连接 |

方向计算使用根部至末端的单位轴向 `axis`：先取 `(axis.y, −axis.x, 0)`，统一候选方向的 X 符号，再归一化并加入 `(0, 0, .12)`，最后去掉沿枝轴的分量并重新归一化。这样偏向正面可见的弯曲平面，并保留少量纵深运动。这里的 `.12` 是归一化前的方向偏置，**不是 12% 摆幅**；实际正负摆动由波形与相位决定。

末端细枝及叶片先执行自身形变，再根据形变后的位置采样所属小枝的位移场。小枝根部固定，其后代的根部随父枝运动。

## 末端细枝：控制枝梢局部弯曲

来源：[garden-twig-motion.ts](../src/lib/garden-twig-motion.ts) 的 `createTwigWind`、`twigSample`、`twigWave`，以及 [garden-tree.ts](../src/lib/garden-tree.ts)。

| 参数 | 当前值 / 规则 | 含义 |
| --- | --- | --- |
| 基础摆幅 | `length * .00896` | 当前 0.896%，与叶簇的 3% 分开控制 |
| 普通末端强度 | `.75 + .25 * random`，约 0.75–1 | 每根枝梢的强度变化 |
| 额外悬垂枝梢强度 | **0.85** | 粗主枝末端额外生成的枝梢使用固定强度 |
| 输入范围 | 强度限制为 0–1 | 不允许负强度或超过基础幅度系数 |
| 作用层级 | 深度 4，以及额外悬垂枝梢 | 其他木质枝条不叠加这一层独立弯曲 |
| 沿枝权重 | `(根部至取样点弧长 / 全枝弧长)²` | 根部相对父枝不动，越靠枝梢弯曲越明显 |
| 权重梯度 | 当地切线 × `2 * along / length` | 叶片使用同一梯度随枝梢弯曲，避免连接处分离 |
| 周期 | **8 秒** | 与叶簇共用时钟，局部相位不同 |
| 普通枝梢相位 | `groupPhase + index * .5 + jitter` | 同组约半周期交错 |
| 相位扰动 | `(random − .5) * .08`，约 ±0.04 周期 | 单枝相对规则位置约 ±0.32 秒 |
| 基础方向角 | 每组随机取 0–2π | 同组使用相近的弯曲平面 |
| 方向角扰动 | `(random − .5) * .24`，约 ±0.12 弧度 | 约 ±6.88°，不是枝条旋转幅度 |
| 方向候选向量 | `(cos(angle), .12, sin(angle))` | 去掉沿曲线中点切线的分量后归一化 |
| 额外悬垂枝梢相位 | `tipPhase + tip * .5` | 两根枝梢相差半周期，不添加上述相位、角度扰动 |
| 风力相位取样 | 枝条曲线参数 `t=.5` 的位置 | 与该枝条附着叶片的局部运动共用 |

0.896% 表示木质枝梢的基础弯曲系数。叶片还会跟随枝条弯曲斜率并叠加自身形变，因此不能将它解释为所有叶尖总位移的上限。额外悬垂枝梢没有所属深度 2 小枝的位移场，只使用自身末端弯曲及叶片运动。

## 叶片主体与叶缘

来源：[garden-leaf-motion.ts](../src/lib/garden-leaf-motion.ts)；个体变化由 [garden-tree.ts](../src/lib/garden-tree.ts) 的 `putLeaves` 生成。

两层都沿**叶片局部 Z 轴**变形，再通过原有实例矩阵映射到树的空间；不是沿屏幕固定方向移动。标准叶片局部长度为 1，实例缩放后才成为实际叶长。

| 主体参数 | 当前值 / 规则 |
| --- | --- |
| 开启时的基础强度 | `leafBladeStrength = .05` |
| 每片叶子的强度系数 | `.7 + .3 * random`，约 0.7–1 |
| 固定区 | 叶片底部 **16%** |
| 形变权重 | `max(0, (y − .16) / .84)²`，叶尖为 1 |
| 周期 | `time * .125`，即 **8 秒** |
| 相位 | 每片叶子独立取 0–1 周期 |
| 关闭时 | 强度为 0 |

| 叶缘参数 | 当前值 / 规则 |
| --- | --- |
| 开启时的基础强度 | `leafEdgeStrength = .01` |
| 每片叶子的强度系数 | `.75 + .25 * random`，约 0.75–1 |
| 慢波 | `time * .25`，**4 秒**；占 **0.65** |
| 快波 | `time * .375`，**8/3 秒**；占 **0.35** |
| 慢波、快波起始相位 | 每片叶子分别独立取 0–1 周期 |
| 左右侧相位偏移系数 | `.08 + .12 * random`，约 **0.08–0.20 周期** |
| 侧边相位组合 | 慢波加 `side * offset`，快波减 `side * offset`；`side` 为左右侧的 −1 / +1 |
| 空间权重 | `across² * sin(πy)²`；`across = x / width(y)` |
| 权重对应的静态叶宽 | `width(y) = .245 * sin(πy)^.85`，与原有叶片几何一致 |
| 固定位置 | 仅此层开启时，叶柄、整条叶脉、叶尖不动 |
| 关闭时 | 强度为 0 |

平滑波形统一为：`triangle = abs(2 * fract(phase + .5) − 1)`，`wave = 2 * triangle² * (3 − 2 * triangle) − 1`。输出在 −1 至 1 之间，转折处平滑，没有弹簧或逐帧随机抖动。叶缘两种频率分别在 8 秒内完成 2 次和 3 次循环，因此全部运动可以每 8 秒重复。

## 风力强弱与空间传播

来源：[garden-wind-field.ts](../src/lib/garden-wind-field.ts)。这里的“风力包络”指随时间变化的幅度乘数，本身不增加新的位移方向。

| 参数 | 当前值 / 规则 |
| --- | --- |
| 强度公式 | `0.85 + 0.15 * cos(2π * (time / 8 − phase))` |
| 强度中心 / 变化量 | **0.85 / 0.15** |
| 最小 / 最大强度 | **0.7 / 1.0**，始终不反转方向 |
| 周期 | **8 秒** |
| 空间相位公式 | `wrap01(.3 + x * .065 + y * .01 + z * .018)` |
| 全局相位偏移 | **0.3 周期** |
| X 方向相位梯度 | **0.065 周期 / 模型单位**，等高等深位置每向右 1 单位峰值约延后 0.52 秒 |
| Y / Z 方向相位梯度 | **0.01 / 0.018 周期 / 模型单位** |
| 流动开关 | `windTravel` 默认 **1**；关闭为 **0** |
| 关闭流动后的行为 | 乘数恒为 **1**，不关闭风动，也不重置时钟 |

传播位置来自静止树形，观察方向改变不会改变树自身的传播方向。横向相距 6 个模型单位、等高等深的两点，强度峰值相差约 3.12 秒（按 8 秒周期循环）。

`windPhase.x` 用于末端枝条与叶片局部运动：有末端枝条时取该枝条中点，否则取叶片自身位置。`windPhase.y` 用于叶簇运动：取所属小枝中点，并传给其全部后代。两种取样分别维持各自尺度的连接关系。

相邻枝条的“约半周期交错”约束局部波形；不同方向、轻微相位扰动和空间强弱变化仍然存在，并不表示屏幕上的每对相邻叶片都严格反向。关闭“风力流动”会去掉 0.7–1 的衰减，部分时刻反而会比默认状态摆得更明显。

## 叠加顺序、随机种子与渲染

1. 叶缘与叶片主体在叶片局部坐标中相加。
2. 末端细枝形变作用于木质枝条和附着叶片。
3. 所属小枝位移场再作用于形变后的点，形成叶簇摆动。
4. 用原有实例变换、手动观察角度及相机完成投影；没有整树自动旋转。

法线随形变修正，表面与阴影使用相同的形变和时钟。实例矩阵不用于逐帧摇摆，颜色和静止树形随机序列不因调整动效而改变。

| 固定随机序列 | 种子 | 生成内容 |
| --- | --- | --- |
| 叶簇 | **37019** | 组相位、单枝相位扰动、单枝强度 |
| 末端细枝 | **82631** | 组相位、方向角、扰动、单枝强度 |
| 叶片主体 | **63721** | 单叶相位、强度 |
| 叶缘 | **95137** | 快慢相位、强度、两侧相位偏移 |

这些序列在建树时生成并固定，不在每帧重新取随机数。几何与颜色使用种子 72819，疏叶使用 51473，树皮纹理使用 983；它们不作为风动调节参数。

透明叶片按静止中心深度排序，只在相机相对树的视角发生变化时重排。运动参数随实例同步重排，日常风动期间不逐帧改写实例数据。小树 → 中树的 1.8 秒、中树 → 大树的 2.2 秒成长过渡是例外：枝干与叶片姿态连续改变时更新实例与排序，结束后恢复静态数据快路径；风动幅度和时钟不变。当前使用 `requestAnimationFrame`，没有独立的固定帧率或风速倍率参数；渲染像素比上限为 **1.75**。

## 播放、暂停与调试

当前视角按钮与调试面板已注释隐藏，页面默认保持正面整树。下表中的调试控件行为指恢复 `TreeStudy.tsx` 内 `GARDEN_DEBUG` 注释后的能力；页面顶部暂停、系统减少动态效果、浇水与自然风动仍正常生效。恢复步骤见 [成长参数](garden-growth.md)。

来源：[garden-motion.ts](../src/lib/garden-motion.ts)、[garden-scene.ts](../src/lib/garden-scene.ts)、[TreeStudy.tsx](../src/components/TreeStudy.tsx)。

| 参数 / 状态 | 当前行为 |
| --- | --- |
| 风动时钟 | 初始为 0，按可见播放区间的真实经过时间推进，循环范围 0–8 秒 |
| 默认状态 | 按本地浇水次数恢复阶段（首次为小树），叶缘、叶片主体、“细枝”、风力流动全部开启，未定格，正面整树视图 |
| “细枝”开关 | 同时控制**叶簇摆动 + 末端细枝弯曲**；共用 `twigStrength` 的 0 / 1 开关，尚未分成两个控件 |
| 低帧率 | 风动按真实经过时间推进，不因逐帧限时而拉长周期 |
| 页面顶部暂停 | 冻结当前风动姿态和时间，恢复后从暂停处继续 |
| 调试定格 | 停止风动时钟，仍允许手动观察方向切换 |
| 离开视口 / 切入后台 | 停止渲染并断开时间基准；恢复后不补算隐藏期间的时间 |
| 关闭全部有效运动层 | 形变归零显示静态树形；时间保留，视角切换结束后停止循环 |
| 系统减少动态效果 | 所有形变强度归零，显示静态树形；时间轴和播放按钮禁用，观察方向直接切换 |
| 开关运动层 / 改主题 / 改画布尺寸 | 不将风动时间重置为 0 |
| 切换成长阶段 | 保留时钟、定格、开关和观察方向；结束单叶 / 单枝检查，返回新阶段整树 |
| 重新加载组件 / 重试初始化 | 恢复累计次数对应的阶段、初始开关、正面视角、0 秒和整树模式 |
| 调试时间轴 | 最小 **0**、最大 **8**、步长 **0.05 秒**；拖动即定格 |
| 时间显示 | 以 **0.05 秒**取整，显示 **2 位小数**；8 秒与 0 秒形态相同 |
| 读数刷新 | 播放时通知间隔至少 **250ms**；面板收起时不更新 React 时间状态 |
| 调试面板范围 | 当前所有环境均注释隐藏；恢复后仅开发环境显示 |

暂停与关闭运动层的含义不同：暂停保留当前形态，关闭对应层会移除该层形变。风力流动开关只是强弱比较，不是额外的有效运动层。

单叶检查清空枝条和叶簇运动属性，只保留叶片自身动效；展示角度绕 Y 轴为 **0.7 弧度**，不增加摆幅系数。单枝检查优先选取左下方、至少附着 3 片叶子的较长细枝；早期阶段没有符合条件的枝条时，使用当前阶段已长叶的较长细枝。保留所属小枝位移场及原有运动参数。两种检查都沿用同一时钟，放大观察不等于增加模型摆幅；检查期间方向按钮禁用。

## 手动观察方向

来源：[garden-motion.ts](../src/lib/garden-motion.ts)。

| 参数 | 当前值 |
| --- | --- |
| 目标角度 | 正面 **0**、侧面 **π/2**、背面 **π**（绕 Y 轴） |
| 持续时间 | `TURN_DURATION = 0.3`，即 **300ms** |
| 缓动 | `p²(3−2p)`，起止速度为零 |
| 单帧推进上限 | **0.1 秒**，仅用于视角切换，不用于风动时钟 |
| 结束容差 | **1e-9 秒**，处理 300ms 边界的浮点累积 |
| 中途再次切换 | 从当前角度转向新的目标，重新计算这次 300ms 过渡 |
| 页面暂停 / 减少动态效果 | 直接到达目标角度，不播放转动过渡 |

风动过程不会持续写入整树旋转角；只有显式的观察方向切换会改变角度。

## 屏幕空间基准与校验

屏幕上的位移还取决于相机和画布。当前桌面画布高度为 `clamp(460px, 65vh, 680px)`，宽度不超过 767px 时高度为 **430px**。整树使用正交相机，位置为 `(0, center.y + 3.2, 18)`（草地版本略微俯视，以显示地面纵深），看向 `(0, center.y, 0)`；视域半高为 `max(size.y * .56, max(size.x, size.z) * .58 / aspect)`。`size` 和中心高度固定使用成树参考范围，阶段切换不改变镜头。早期枝条较短，同一百分比的世界空间及屏幕位移也较小。这些属于观察尺度，不是风动幅度参数。

加入草地前的 3% 叶簇摆幅历史计算基准（相机高度偏移为 0.45，以下数值不作为新视角的精确测量）：窗口 **1280×720**、画布 **1120×468**、正面视角、所有运动开启。对 **8794** 个叶尖采样完整 8 秒周期，每 **0.125 秒**一次，共 **64** 个时刻；求同一叶尖任意两个采样时刻的最大投影距离，再统计所有叶尖：

| 统计量 | 历史估算 |
| --- | --- |
| 位移中位数 | **1.45px** |
| 第 95 百分位 | **2.92px** |
| 最大值 | **4.28px** |

这是基于几何与相机的 CSS 像素投影计算，不是截图测量；不包含遮挡、透明叠色、阴影与高光变化的视觉影响。叶缘权重在叶尖为零，因此叶尖统计不能代表叶缘微动。相位之间存在叠加或抵消，局部参数减少多少，不等于最终屏幕位移必然减少相同比例。

[屏幕位移测试](../tests/garden-wind-visibility.test.mjs) 为降低开销，每隔 5 片叶子、每隔 0.25 秒采样；当前断言为中位数 **大于 1px 且小于 2px**、第 95 百分位 **小于 4px**、最大值 **小于 5px**，并检查主干固定与无默认整树旋转。其余测试分别覆盖连接、波形周期、相位交错、法线、阴影和播放时间控制。

相关检查命令（使用项目支持的 Node.js 版本）：

```sh
node --test tests/garden-*.test.mjs
```

## 浇水的独立反馈

这组参数只在点击浇水时短暂生效，不改变上面的常驻风动基准。

| 参数 | 当前值 / 行为 |
| --- | --- |
| 一轮反馈及按钮禁用 | `WATERING_SECONDS = 2.6` 秒 |
| 落点 / 水滴数量 | 当前阶段的 12 处外露叶片，每处 2 滴，共 24 滴 |
| 起始高度 | 当前树冠最高落点上方 0.9 个场景单位 |
| 错开间隔 | 落点之间 35ms，同列两滴间隔 180ms |
| 下落时长 | `0.65 + sqrt(高度差) × 0.15` 秒，沿竖直方向加速 |
| 水滴半径 / 半长 | 第一滴 `.042 / .105`，第二滴 `.033 / .105` |
| 叶片响应范围 | 落点附近 X/Z 半径 `1.05`、Y 半径 `.8`，平滑衰减 |
| 叶片瞬态弯曲系数 | `.38 × 叶片个体权重 × 局部脉冲`；沿叶长使用原有二次弯曲，固定根部 16% |
| 响应时长 / 频率 | 每处最多 `.9` 秒，约 2.4Hz，邻叶额外错开 0–45ms |
| 衰减 | `exp(-2.8 × age)`，开始 55ms 渐入，末尾 250ms 归零 |
| 与风动的关系 | 独立时钟与 uniform；只叠加叶片弯曲及对应法线/阴影，不修改枝条或树的姿态 |
| 暂停和恢复 | 隐藏/离屏暂停计时；页面暂停、减少动态效果、手动切换阶段/检查模式则取消，恢复不补播；浇水触发的相邻阶段成长与本次水滴衔接 |

实现位于 `garden-watering-motion.ts`、`garden-water-drops.ts` 和 `garden-leaf-motion.ts`。

`WATER_LEAF_RESPONSE` 集中管理瞬态摆幅、衰减及频率。在 1120×468 桌面画布、正面视角下，隔离常驻风动，对落点附近权重大于 0.5 的叶片采样，叶尖相对静止位置的最大额外位移中位数约为 **1.85px（小树）/ 1.80px（大树）**；第 95 百分位约为 **3.26px / 3.43px**。这是投影估算，不包含遮挡与透明叠色；测试约束中位数 1.4–2.6px、95% 小于 4px、最大值小于 5px，避免再次变成难以辨认的亚像素反馈。

## 后续调整时的对应关系

| 想调整的观感 | 应优先查看的参数 |
| --- | --- |
| 整个树冠或叶簇移动太大 / 太小 | `createBranchWind` 的 **.03** |
| 末端枝梢相对叶簇弯曲太多 / 太少 | `createTwigWind` 的 **.00896** |
| 单片叶子翻弯太明显 / 太弱 | `setBladesEnabled` 的 **.05** |
| 叶片边缘细碎微动太多 / 太少 | `setEdgesEnabled` 的 **.01**，及慢波 / 快波的 **.65 / .35** 配比 |
| 风的强弱起伏太明显 / 太弱 | 强度包络的 **.85 / .15**；同时保持最大乘数约束 |
| 节奏需要改变 | 时钟、各层频率和包络周期一起核对，不能只修改一个 `8` |
| 需要分别观察叶簇与末端细枝 | 当前“细枝”开关合并两层，需先拆分控制再对照 |

用户确认后的基准是本表当前值。后续修改时同步更新本表、SPEC 和受影响的校验，并保持观察窗口、视角与开关状态一致；不要用末端细枝的幅度替代叶簇幅度，也不要通过修改相机尺度掩盖摆幅变化。

# 树的成长阶段

实现日期：2026-10-18；三阶段更新：2026-10-19。适用于 `/garden/` 和 `/en/garden/`。

当前页面仅显示正面整树、浇水按钮和累计次数。视角切换及“生长与风动调试”已注释隐藏，开发环境同样隐藏；下文的手动预览能力保留，恢复后可用。恢复方法：在 [TreeStudy.tsx](../src/components/TreeStudy.tsx) 中搜索 `GARDEN_DEBUG`，取消相关 import、状态、effect、初始化、时间回调与 JSX 的注释；恢复时间回调时移除临时的 `const onWindTime = undefined`。底层风动、成长、视角接口及样式均保留。

首次访问显示小树。每次浇水累计 1 次：0–24 次为小树，25–49 次为中树，达到 50 次为大树；大树阶段仍可继续浇水。每个浏览器独立保存进度，访客之间不共享。开发环境展开“生长与风动调试 / Growth & wind study”可以预览三个阶段，预览不改变实际次数，下一次浇水恢复对应阶段。小树 → 中树支持 1.8 秒分层生长过渡，中树 → 大树沿用相同顺序放缓至 2.2 秒；反向和跨级预览即时切换。

## 形态与参数

参数集中在 [garden-growth.ts](../src/lib/garden-growth.ts)。枝条数包含主干及各级细枝；叶片数为实际渲染实例数。

| 参数 | 小树 | 中树 | 大树 |
| --- | ---: | ---: | ---: |
| 累计浇水次数 | 0–24 | 25–49 | 50 及以上 |
| 主干高度系数 | 0.72 | 0.86 | 1 |
| 木质粗细系数 | 0.67 | 0.84 | 1 |
| 主侧枝伸展系数 | 0.62 | 0.81 | 1 |
| 各级子枝伸展系数 | 0.72 | 0.86 | 1 |
| 单片叶长系数 | 0.92 | 0.96 | 1 |
| 已生长的粗主枝 | 8 | 11 | 14 |
| 全部木质枝条数 | 417 | 1145 | 2395 |
| 叶片数 | 1490 | 4075 | 8794 |
| 模型宽 × 高（约） | 5.93 × 5.18 | 7.54 × 6.40 | 9.06 × 7.63 |

所有系数相对成树参考结构。每根子枝从当前阶段父枝的对应附着点向外伸展；整树 `group.scale` 始终为 `(1, 1, 1)`，叶片尺寸也独立控制，因此不是成树模型的等比缩放。

三个阶段使用同一固定种子的枝条谱系。尚未长出的分枝也消耗原有随机序列，但不建立渲染网格；早期已有的分枝和叶片包含在后续阶段内，保留相同的叶片运动相位。新增中树保留已有小树和大树的几何、实例矩阵、颜色及风动属性指纹；中树新增的分枝在大树阶段继续保留。

## 相邻阶段的生长过渡

第 25 / 50 次浇水时立即保存次数，水滴先落向原阶段树冠；第一滴预计接触叶片后，开始小树 → 中树 / 中树 → 大树的生长。开发面板从小树切换到中树、从中树切换到大树时直接预览，不改变次数。恢复存储、刷新、语言切换及其他标签页同步直接显示保存的最终阶段，不重播过渡。反向或跨级预览直接切换。

| 时序（从开始生长计时） | 小树 → 中树 | 中树 → 大树 |
| --- | --- | --- |
| 总时长 | 1.8 秒 | 2.2 秒 |
| 主干平滑增粗、长高 | 前 0.65 秒 | 前约 0.79 秒 |
| 侧枝开始逐层伸展 | 约 0.12 秒起 | 约 0.15 秒起 |
| 新叶按枝簇错开展开 | 约 0.72–0.97 秒起 | 约 0.88–1.19 秒起 |

- 根部固定，新枝从父枝当前连接处长出，新叶从叶柄展开；已有叶片持续跟随原枝条。中树 → 大树只拉长时序，沿用已确认的生长顺序。
- 使用两端速度为零的 smoothstep 插值，无弹跳、整树缩放或自动旋转。相机、配色、透明度及现有风动参数保持不变，风动时钟连续。
- 只更新一套目标阶段网格。枝条用固定谱系索引对应，叶片用固定 ID 对应；枝条局部坐标随父枝连接点推进。过渡期间更新实例排序，结束后恢复目标阶段的精确几何、材质相关颜色和风动数据，并停止逐帧生长计算。
- 页面离屏或隐藏时暂停计时；开启页面暂停或系统减少动态效果时直接完成生长。切换到其他阶段、进入单叶 / 单枝检查时结束旧过渡，再执行选择，避免遗留回调。
- 生长期间禁用浇水按钮；水滴反馈结束而生长尚未结束时显示“生长中… / Growing…”，直到过渡完成才恢复浇水，避免下一次点击截断新叶展开。
- 时长、相邻阶段选择及插值实现在 [garden-growth-transition.ts](../src/lib/garden-growth-transition.ts)，没有引入额外依赖。

## 风动、材质和取景

三个阶段共用现有 8 秒风动时钟，叶簇 3%、末端细枝 0.896%、叶片主体 5%、叶缘 1% 的相对摆幅保持不变。枝条变短后，风动使用该阶段的真实枝长重新计算；主干和粗主枝固定。材质继续使用浅绿色板、不透明度 0.74 和现有柔和清漆高光，详见 [动态参数](garden-motion-parameters.md)。

整树视图使用统一的成树参考范围：宽 9.056、高 7.633、深 6.001，中心高度 3.8054。镜头和地面位置不随阶段改变，让身高与树冠的增长直接可见；移动端沿用同一范围的自适应取景。单叶和单枝检查仍使用各自的放大镜头。

阶段切换保留观察方向、风动时间、定格状态、页面暂停和各运动层开关。若正在单叶或单枝检查，切换到另一阶段时返回整树；旧检查对象与旧树的几何、实例资源、材质和纹理一起释放。同一阶段按钮重复点击不会重新创建树。刷新页面根据本地累计次数恢复对应阶段及默认风动设置；开发面板的临时预览选择不保存。

## 独立浇水进度

[浇水逻辑](../src/lib/garden-progress.ts) 中的 `MEDIUM_WATERINGS = 25` 和 `MATURE_WATERINGS = 50` 分别控制进入中树、大树的累计次数。原有计数直接沿用，无需迁移或清空。次数使用 `localStorage` 的 `fine:garden:waterings:v1` 保存为非负安全整数，中英文页面共用同一个键，不记录访客身份、不发送网络请求。不同浏览器、设备、站点来源分别保存；清除站点数据会重置进度。同浏览器其他标签页通过 `storage` 事件更新，计数前读取最近保存值。

树下提供浇水按钮和累计次数，没有升级倒计时。有效点击立即累计，按钮显示“浇水中…”并禁用 2.6 秒，防止同一轮反馈中重复操作；若成长过渡仍在进行则等待完成后再恢复浇水，不设每日次数限制。次数变化通过可访问状态区域播报。

浇水时，24 滴浅蓝色水滴（`#78b8e0`）从树冠上方错落落下；12 个落点根据当前阶段的实际叶片位置挑选，优先使用外露的冠层。水滴接近叶片后收缩消失，附近叶片产生约 0.9 秒的衰减颤动（弯曲系数 0.38、频率 2.4Hz、衰减系数 2.8），接触后的弯曲与回弹在整树视图中可辨认，叶柄固定，不转动树干或重置原有风动。整体最长 2.6 秒，水滴实例缓冲重复使用，无持续生成或遗留粒子。

落点与时序见 [garden-watering-motion.ts](../src/lib/garden-watering-motion.ts)，水滴绘制见 [garden-water-drops.ts](../src/lib/garden-water-drops.ts)，叶片响应叠加在现有局部弯曲及阴影中。动画回调与保存进度回调分离，因此刷新、语言切换和其他标签页同步不会重播。隐藏页面或离开视口暂停计时；手动切换成长预览/检查模式取消旧浇水动画；浇水触发的两个相邻阶段过渡均与本次水滴连续衔接。暂停页面动效或开启系统减少动态效果时取消/跳过动画，仍可浇水计数，恢复播放不会补播。

存储读取被禁用时使用本页内存计数；写入失败时保留已有次数和新增加的次数，显示无法持久保存的说明。非法或损坏的存储值按 0 处理，读入时不会主动覆写存储。没有账户或云端同步，同一浏览器配置中的使用者共用这份本地进度。

## 验证

[过渡测试](../tests/garden-growth-transition.test.mjs) 覆盖两段过渡的原有叶片起点、枝干连续性、根部中心固定、最终阶段数据完全一致、动态排序后的连续更新，以及带接触延迟的有限时钟；另验证 25 / 50 次对应时长、原有小树 → 中树中间姿态不变、2.6 秒浇水反馈结束后大树仍可继续生长。[成长测试](../tests/garden-growth.test.mjs) 覆盖小树与大树指纹、固定镜头范围、枝叶与尺寸递增、叶片身份延续、确定性生成、风动属性、检查模式与资源释放。原有风动测试继续校验连接、相位、8 秒周期及成树屏幕摆幅。[浇水测试](../tests/garden-progress.test.mjs) 验证浏览器间隔离、刷新恢复、阈值前后状态、成树后累计、顺序跨标签更新、无效数据与存储失败降级。[水滴动画测试](../tests/garden-watering-motion.test.mjs) 覆盖三个阶段的真实落点、下落方向、有限时钟、与风动独立的表面/阴影参数及资源释放。

# 标题分行入场计划

依据 SPEC.md 中用户确认的六条要求实施。

1. 把标题两行分别包裹为 `.hero-title-line`，保留第二行强调色。
2. 移除 `.hero-content` 入场，为两行添加 1000ms 的淡入与 12px 上移，第二行延迟 300ms，使用 `cubic-bezier(0.22, 0.61, 0.36, 1)`。
3. 动画仅置于 `prefers-reduced-motion: no-preference`，不增加主题或悬停触发。
4. 构建并在浏览器验证时序、最终状态、主题切换及手机排版。

顺序执行，无新增依赖；主要风险是两个 span 继承同一强调色，及父子动画叠加，实施时分别限定第二行颜色并删除父级动画。
